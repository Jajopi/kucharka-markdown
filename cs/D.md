# Co se dá půjčit

| Co | Kde | Za kolik |
|------------------------|------------------|------------------|
| Vysavač | Vrátnice A, B | 5 Kč / 30 min |
| Žehlička | Vrátnice A, B | 5 Kč / 30 min |
| Žehlicí prkno | Vrátnice A, B | Zdarma na dva dny[^1] |
| Pračka, Sušička | V aplikaci | 23 Kč / cyklus |
| Sušárna | Vrátnice A | Zdarma na dva dny[^1] |
| Klíč od WC v přízemí A | Vrátnice A | Zdarma |
| Studovna / lab na A | Vrátnice A | Zdarma |
| Ping-pong/Aerobik | Vrátnice A | Zdarma |
| Hudební zkušebna | Vrátnice A | Zdarma oproti průkazu |
| Troubárna | Vrátnice A, B | Zdarma oproti průkazu (vrátit ten den) |
| Plechy na pečení k troubárně | Vrátnice A | Zdarma (vrátit čisté) |
| Posilovna | Vrátnice A, B | Zdarma oproti průkazu |
| Klavírní místnost | Vrátnice A, B | Zdarma |
| Malá klubovna (+ fotbálek) | Vrátnice B | Zdarma |
| Velká klubovna | Vrátnice B | Příspěvek na úklid[^2] |
| Ekumenická místnost | Vrátnice B | Zdarma[^3] |
| Kolárna | [Správci koláren](https://listopad.koleje.cuni.cz/kolarny) | Záloha na klíč[^4] |
| Stěhovací vozík | Sklad prádla | Zdarma[^5] |
| Pumpa na kola | Vrátnice A, B | Zdarma |
| Pumpa na míče | Vrátnice A | Zdarma |
| Sportovní potřeby | Vrátnice A/ B | Zdarma[^6] |
| Teploměr | Vrátnice A | Zdarma |
| Váha na zavazadla[^7] | Vrátnice A, B | Zdarma |
| REkrabička | Menza | Záloha[^8] + 2 Kč / použití |
| Lampička | Pan Holub | Záloha[^9] |

[^1]: Po dvou dnech se platí 20 Kč za každý den navíc.
[^2]: Obvykle 100 Kč, v případě poklidné akce je možné ho odpustit.
[^3]: Je potřeba dohodnout se na využití se správcem místnosti.
[^4]: Většinou je záloha 200 Kč.
[^5]: Půjčení není garantováno, je založeno na dobré vůli paní ze skladu.
[^6]: Viz [Půjčování sportovních potřeb](#pujcovani-sportovnich-potreb).
[^7]: Váhy jsou mechanická na Ačku a digitální na Bčku.
[^8]: Záloha na REkrabičku je 80 Kč.
[^9]: Záloha na lampičku je circa 200 Kč.
